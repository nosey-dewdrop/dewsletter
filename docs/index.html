You write down what you can do. Every morning the engine reads 450 live AI/ML internship listings, scores each one against your profile, and mails you only the new matches. Every match carries its named reasons, so you can see exactly why it was sent. When nothing new fits, no mail is sent.

Why should this exist?

Listings are scattered, stale and noisy (42 duplicates deleted just this morning), but that is not the real problem. The real problem: people still fail to find internships. The one who wins is usually not the best candidate. It is the most alert one, the one who saw the posting first, the one with the most connections. This site exists to delete that advantage. The engine reads every listing every morning, for everyone, so nobody wins just by watching job boards harder than you.

How does it work?

Sources are parsed into a single schema every morning. Each listing carries company, position, location, remote flag, salary when public, and the application link. A listing with no link still enters, marked link not found, search it yourself. Your profile (interests, skills, level, location) is scored against every listing; a point is never awarded without a reason string attached. No black box, no language model.
