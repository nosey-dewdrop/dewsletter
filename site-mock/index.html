You write down what you can do. Every morning the engine reads 494 live AI/ML internship listings, scores each one against your profile, and mails you only the new matches. Every match carries its named reasons, so you can see exactly why it was sent. When nothing new fits, no mail is sent.

Abstract

Internship listings are scattered, stale and noisy. This site maintains a curated, daily-refreshed dataset of 494 AI/ML internships suitable for students (single-applicant, no referrals required), and matches them to your profile with a fully deterministic scoring engine: no black box, no language model. Submit a profile in Algorithm 1; results arrive by mail as new positions appear.

1Method

Sources are parsed into a single schema every morning. Each listing carries company, position, location, remote flag, salary when public, and the application link. A listing with no link still enters, marked link not found, search it yourself. Your profile (interests, skills, level, location) is scored against every listing; a point is never awarded without a reason string attached. The engine contains no language model.
