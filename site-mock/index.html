Abstract

Internship listings are scattered, stale and noisy. This site maintains a curated, daily-refreshed dataset of 494 AI/ML internships suitable for students (single-applicant, no referrals required), and matches them to your profile with a fully deterministic scoring engine — every match ships with its named reasons, no black box. Upload a CV or fill the profile below; matching results arrive by mail when new positions appear. Nothing is sent when nothing is new.

1Method

Sources are parsed into a single schema every morning. Each listing carries company, position, location, remote flag, salary when public, and the application link — a listing with no link still enters, marked link not found, search it yourself. Your profile (interests, skills, level, location) is scored against every listing; a point is never awarded without a reason string attached. The engine contains no language model.
